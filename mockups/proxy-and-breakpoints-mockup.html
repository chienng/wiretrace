More devices, port 8889, encrypted hosts, breakpoints, rewrite, map local, map remote (mockups for spec 022)

One Wiretrace, one window, one Wi-Fi proxy port. Up to four phones share it; the tester allows each one, and can remove it again. The default port becomes 8889, and it can be changed from the window. Connections Wiretrace does not decrypt show as Encrypted rows, and one right-click adds their host to the preset's API hosts. Rules can pause a request or a response at a breakpoint so it can be edited, rewrite headers and JSON fields, and map an endpoint to another server; a response becomes a mock file in one step (Map local). Designed at 1440 px. All data is illustrative; purple dashed outlines mark what is new.

10a. Several phones on one port: the device list, and a new device asking to join

Always visible: the Wi-Fi proxy address with Copy and Change… (port), then each accepted phone by IP and request count. Click one to filter Traffic; ⚠ counts failed TLS handshakes.
The banner turns solid amber and pulses 3 times when a new device asks (steady with Reduce motion); the tab title shows "(1)". Allow… joins it to this session; Switch to it… starts over with only that device.
The Device column, next to Time, shows which phone sent each request ("This Mac" for the simulator or emulator). The selected request names it too.

10b. Allow a device: the tester checks the address first

The limit is 4 devices besides this Mac. At the limit, Allow… in the banner is disabled: "This session accepts 4 devices at most. Switch to it to start a session with only this device."

10c. Remove a device from the session

Hovering a device row shows ×; right-click offers Remove from this session… too. Any accepted device can be removed, the first one included, and its place becomes free.
The proxy refuses it from then on: new connections and the next request on an open one. Encrypted tunnels it already has end when the phone closes them.
With no device left, nobody gets in automatically: every device then has to be allowed from the banner.

10d. Encrypted connections in Traffic, and right-click to decrypt a host

Hosts outside the preset's API hosts pass through without being read. Each connection is now a grey Encrypted row: host and port, when it opened, how long it stayed open. No request or response content, and no size.
Right-click (or Decrypt this host… in the detail) adds the host, or its parent domain, to the API hosts. Show encrypted and the Encrypted quick filter hide or isolate these rows.
Encrypted rows stay in memory for the live session only: not in flows.mitm, the HAR, a bug report or a previous session.

10e. Decrypt a host: saved to the preset and applied without a restart

The host is written to presets/default.yaml and applied to the running session: new connections to it are decrypted, open ones stay encrypted until the app reconnects. Removing a host stays in Edit presets (which restarts the session, as today).

10f. Setup: port 8889 by default, with Change port…

8889 by default, so Charles (8888) can run on the same Mac. The port is kept for the next sessions; ./wiretrace start --port N overrides it for one run.

10g. Change the Wi-Fi proxy port

Opened from Change… in the sidebar's Wi-Fi proxy box, or from Setup. Changing the port saves this session and starts a new one on the new port, like a device switch. Accepted and allowed devices are not carried over: the first phone to connect is accepted again.

10h. A breakpoint rule: pause a request, a response, or both

A breakpoint is a rule with the action Pause. It matches like any rule (method, host, path, body) and follows the rule order. It pauses only while the Wiretrace window is open, and at most 10 requests at once; the 11th passes through unpaused.

10i. Paused request: edit it, then Continue or Abort

The title bar counts paused requests, with Continue all. Paused rows are orange with a PAUSED tag.
Method, path and query, headers and a text body can be edited. Host, Content-Length and Transfer-Encoding cannot: Wiretrace sets them.
Abort closes the request (the app sees a network error). If no Wiretrace window is open for 30 s, every paused request continues unchanged.

10j. Paused response: change what the app receives

At the response, the status, headers and a text body can be edited. A request that was edited or answered at a breakpoint keeps an EDITED tag and a "breakpoint" note in its comment, so a bug report shows it.

10k. A Rewrite rule: change headers and JSON fields on every matching request

Changes rules (Map remote, Rewrite) all apply, in order. Then the first Answers rule that matches (mock, status, delay, drop, pause) ends the search, as today.
Each change: request or response; set, add or remove a header; set or remove a JSON field by path. Host, Content-Length and connection headers cannot be changed.
When Wiretrace answers the request itself (mock, status, drop, mock file), the changes are not applied: nothing went to the server.

10l. A Map remote rule: send matching requests to another server

Scheme, host and port change; path and query stay. Host is set to the target, and the target's certificate is checked as usual.
Not this Mac or addresses on your network: refused on save, and again when the name resolves (the app then gets 502). That keeps phones from reaching this Mac's network through a rule.
The app's tokens and cookies go to the target too. With http, the editor adds a plain-text warning.

10m. Mapped and rewritten requests in Traffic, and what changed

MAPPED and REWRITTEN tags. Traffic, Hosts and filters keep the host the app asked for; the detail adds Sent to.
The Changes tab lists each change, applied or skipped and why. Secret header values are masked. Request and Response show what was really sent and received.
The comment names the rules and the target, never a value, so the HAR and a bug report show that a request was mapped or rewritten.

10n. Right-click a request: Map local…

Request rows get a right-click menu. Map local… is also in the detail, next to Copy as mock. Disabled for a previous session, a request still in flight, or a binary or over-1-MiB response (the tooltip says which).

10o. Map local: save the response as a mock file and answer with it

The file goes into the preset's mocks folder, under saved/ by default, so it answers only through its rule. An existing file needs Replace.
Answer with it now adds a Mock rule at the top of the rules. Off: only the file is written.
The body is editable before saving: change a value, or remove tokens and personal data.
